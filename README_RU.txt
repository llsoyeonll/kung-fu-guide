ПРОВЕРКА EMAIL — 0.0.26

Что изменено:
1. При регистрации Email нужно ввести дважды.
2. Проверяются формат адреса и частые опечатки в доменах Gmail/Yandex/Mail.ru.
3. После регистрации аккаунт НЕ получает доступ, пока пользователь не подтвердит Email по ссылке из письма.
4. Вход для неподтверждённого Email дополнительно блокируется на клиенте.
5. Добавлена кнопка «Повторно отправить письмо подтверждения».
6. Работает и на GitHub Pages, и на Cloudflare Pages: адрес возврата определяется автоматически.

Важно:
Ни браузер, ни Supabase не могут надёжно узнать заранее, существует ли конкретный ящик, например someuser@gmail.com.
Если адрес синтаксически правильный, но ящика нет, письмо вернётся отправителю как «550 5.1.1 NoSuchUser».
Однако такой пользователь теперь не сможет войти и заполнить профиль, потому что не сможет подтвердить Email.

Для работы подтверждения в Supabase должно быть включено:
Authentication -> Providers -> Email -> Confirm email.
По текущей отправке письма подтверждения эта функция у проекта уже используется.
