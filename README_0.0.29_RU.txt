Версия 0.0.29

Изменения:
- в профиле/регистрации добавлены серверы: Америка, Китай, Малайзия; «Пиратка» переименована в «Пиратка CN»;
- в каталоге пользователей показывается выбранный сервер;
- неподтверждённые email и заблокированные аккаунты видны только администратору; неподтверждённые помечаются «Не подтвержден»;
- обычные пользователи видят только подтверждённые, заполненные и незаблокированные профили;
- на страницу «Школы, Фракции, Секты» добавлены присланные изображения и названия без создания новых страниц;
- добавлен переключатель RU / EN на всех страницах, включая регистрацию, вход и окно блокировки. Критические элементы интерфейса переводятся локально; при EN также подключается автоматический перевод остального русскоязычного содержимого страницы.

База Supabase уже обновлена для новых серверов и безопасного каталога пользователей.
