Назначение предмета

Яшмовые Куклы

Яшмовые Куклы — вспомогательные предметы, которые дают персонажу дополнительные характеристики.

Для очистки используются Ваучеры Яшмовой Куклы. Быструю очистку можно провести при наличии этих ваучеров.

Быстрая очистка

Проверьте количество Ваучеров Яшмовой Куклы перед началом очистки.

04

Действия с куклой

Основные возможности

ЗМ

Замена

Выберите улучшенный атрибут для замены дополнительного атрибута. Яшмовой Кукле нельзя назначить несколько дополнительных атрибутов одного типа.

ОЧ

Очистка

Используйте Серебро или Ваучеры Яшмовой Куклы для заточки и получения дополнительных атрибутов. Стоимость серебряной заточки увеличивается с каждым использованием и сбрасывается на следующий день.

МД

Модернизация

Используется для повышения уровня и значения дополнительных атрибутов. Качество атрибута определяет величину увеличения параметров.

05

Игровой интерфейс

Очистка куклы

!
Подсказка

Журнал сохраняет характеристики, полученные при очистке. После выхода из системы журнал очищается. Информация журнала отображается в каталоге bin64 игрового клиента.

06

Порядок использования

Правила

  1. 01

    Заточка

    Перетащите Яшмовую Куклу Золотого или Яшмового качества из рюкзака в слот в верхней части левой панели либо щёлкните по ней правой кнопкой мыши. Нажмите «Заточить», чтобы использовать Серебро или Ваучеры Яшмовой Куклы. После заточки кукла случайным образом получает дополнительные атрибуты Медного, Серебряного, Золотого или Яшмового качества, а также некоторое количество Халцедонов.

  2. 02

    Замена

    Если у куклы меньше 5 дополнительных атрибутов, улучшенный атрибут можно добавить к текущим либо использовать для замены одного из них. Если у куклы уже 5 дополнительных атрибутов, доступна только замена одного из текущих.

  3. 03

    Ограничение атрибутов

    Яшмовой Кукле нельзя назначить несколько дополнительных атрибутов одного типа. Если заменяемый атрибут имеет уровень выше первого, при замене вы получите некоторое количество Халцедонов в зависимости от его уровня.

  4. 04

    Улучшение

    Дополнительный атрибут, полученный через заточку, имеет 1-й уровень. Нажмите «Улучшить», чтобы потратить Халцедоны и повысить уровень атрибута. Халцедоны можно получить при заточке и замене. Качество Яшмовой Куклы определяет возможность повышения уровня, а качество дополнительного атрибута — величину прироста параметров.
